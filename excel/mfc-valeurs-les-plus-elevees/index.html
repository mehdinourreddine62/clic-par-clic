10 valeurs les plus élevées
Le nombre se règle : 3 pour un podium

Gérer les règles
Pour revoir ou supprimer les règles
Résumé écrit des étapes
  1. « 10 valeurs les plus élevées », réglé sur 3 : le podium se colore.
  2. « Au-dessus de la moyenne » : Excel calcule la moyenne tout seul et colore ce qui la dépasse.
  3. Farid n'est pas sur le podium, mais il dépasse la moyenne : sa cellule se colore aussi.
  4. Les règles se cumulent. Pour les revoir ou les supprimer : Mise en forme conditionnelle › Gérer les règles.
