Utiliser le mode Présentateur

Voir ses notes, le minuteur et la diapositive suivante pendant que le public voit la diapositive en cours.

Diaporama › Utiliser le mode Présentateur : vous verrez vos notes sur votre écran pendant l'oral.

Cette leçon vous a aidé ?

Clavier : ← → pour changer d'étape, Espace pour lancer ou mettre en pause.

Syntaxe Diaporama › Utiliser le mode Présentateur · Alt + F5

Résumé écrit des étapes
  1. Diaporama › Utiliser le mode Présentateur : vous verrez vos notes sur votre écran pendant l'oral.
  2. Sans second écran, Alt + F5 ouvre ce mode pour vous entraîner chez vous.
  3. À gauche, en grand, la diapositive que le public voit sur le vidéoprojecteur.
  4. En haut, le minuteur : il indique depuis combien de temps vous parlez.
  5. À droite, la diapositive suivante : vous pouvez annoncer la suite avant de cliquer.
  6. En dessous, vos notes, que le public ne voit pas : quelques mots clés suffisent.
  7. La flèche droite passe à la diapositive suivante ; le minuteur continue de tourner.
  8. Échap termine la présentation et revient à l'écran de travail.

Comment voir ses notes pendant une présentation PowerPoint ?

Écrivez vos notes sous chaque diapositive (bouton Notes de la barre d'état), puis cochez Diaporama › Utiliser le mode Présentateur. Branché à un vidéoprojecteur, PowerPoint montre la diapositive au public et, sur votre ordinateur, la diapositive en cours, la suivante, vos notes et un minuteur. Sans second écran, Alt + F5 ouvre ce mode pour répéter.

Pour s'entraîner

Alt + F5

Chronométrez une répétition complète : le minuteur vous montre si vous tenez le temps prévu.

Erreurs fréquentes

  • Le public voit le mode PrésentateurLes écrans sont inversés : en haut du mode Présentateur, Paramètres d'affichage › Permuter le mode Présentateur et le diaporama.
  • Les notes sont trop petitesUtilisez les boutons de taille du texte sous les notes.

Questions fréquentes

Où écrire les notes ?

Sous la diapositive, dans la zone ouverte par le bouton Notes de la barre d'état.

Comment mettre le minuteur en pause ?

Avec le bouton pause à côté du minuteur.

Le jury voit-il les notes ?

Non, ni à l'écran ni dans le PDF exporté en diapositives.
