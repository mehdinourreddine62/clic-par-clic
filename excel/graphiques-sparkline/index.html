Graphiques sparkline

Un mini-graphique dans une cellule, pour chaque ligne.

fx

Sélectionnez les cellules vides, puis Insertion › Sparkline › Courbe.

Cette leçon vous a aidé ? Partagez-la avec vos camarades.

Clavier : ← → pour changer d'étape, Espace pour lancer ou mettre en pause.

Syntaxe Insertion › Sparkline

Les valeurs à dessiner
Plage d'emplacement
Les cellules qui reçoivent les mini-graphiques
Types
Courbe ou histogramme
Résumé écrit des étapes
  1. Sélectionnez les cellules vides, puis Insertion › Sparkline › Courbe.
  2. Indiquez les données : chaque ligne reçoit son mini-graphique, dans une seule cellule.
  3. D'un coup d'œil : les stylos montent, les cahiers baissent.
  4. L'onglet Sparkline permet de passer en histogramme : la barre la plus haute ressort en couleur.
