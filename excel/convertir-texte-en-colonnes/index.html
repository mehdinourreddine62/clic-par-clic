Séparer un texte en colonnes

Répartir des données collées dans une seule colonne.

fx

Un fichier importé arrive souvent avec tout dans la même colonne.

Cette leçon vous a aidé ? Partagez-la avec vos camarades.

Clavier : ← → pour changer d'étape, Espace pour lancer ou mettre en pause.

Syntaxe Données › Convertir
Délimité
Les valeurs sont séparées par un caractère
Séparateur
Point-virgule, virgule, tabulation ou espace
Résumé écrit des étapes
  1. Un fichier importé arrive souvent avec tout dans la même colonne.
  2. Sélectionnez la colonne, puis Données › Convertir.
  3. Indiquez le caractère qui sépare les valeurs : ici, le point-virgule.
  4. Chaque valeur prend sa colonne, et les nombres redeviennent de vrais nombres.
