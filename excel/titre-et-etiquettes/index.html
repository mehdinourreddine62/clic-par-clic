Résumé écrit des étapes
  1. « Ventes » ne dit pas grand-chose. Double-cliquez sur le titre pour le modifier.
  2. Un bon titre annonce le message, pas seulement le sujet.
  3. Ajoutez les étiquettes de données pour afficher les valeurs.
  4. Les valeurs étant écrites, l'axe vertical fait doublon : on peut le retirer.

Comment modifier le titre et afficher les valeurs d'un graphique Excel ?

Double-cliquez sur le titre d'un graphique pour le réécrire : un bon titre annonce le message (« Les stylos se vendent le mieux ») plutôt que le sujet (« Ventes »). Éléments de graphique (le bouton +) › Étiquettes de données affiche la valeur sur chaque barre ; l'axe vertical devient alors inutile et peut être retiré.

Exemple

Les valeurs 320, 260, 210 et 140 s'affichent sur les barres : le lecteur n'a plus à les estimer sur l'axe.

Erreurs fréquentes

  • Le titre ne se modifie pasIl est lié à une cellule : changez le texte de la cellule, ou cliquez dans la barre de formule pour supprimer le lien.
  • Les étiquettes se chevauchentRéduisez la police, ou choisissez la position Bord intérieur.

Questions fréquentes

Comment lier le titre à une cellule ?

Sélectionnez le titre, tapez = dans la barre de formule, puis cliquez sur la cellule.

Comment afficher des pourcentages ?

Dans un graphique en secteurs, cochez Pourcentage dans les options des étiquettes.

Comment ajouter un titre d'axe ?

Éléments de graphique › Titres des axes.
