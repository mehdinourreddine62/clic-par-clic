Utiliser une cellule d'une autre feuille

Reprendre un résultat calculé sur une autre feuille.

fx

Les données sont sur la feuille Ventes, mais on veut leur total ici, sur Synthèse.

Clavier : ← → pour changer d'étape, Espace pour lancer ou mettre en pause.

Syntaxe =Ventes!B4
Ventes
Le nom de la feuille
!
Sépare la feuille et la cellule
Apostrophes
Ajoutées si le nom contient un espace
Résumé écrit des étapes
  1. Les données sont sur la feuille Ventes, mais on veut leur total ici, sur Synthèse.
  2. Tapez = puis cliquez sur l'onglet Ventes et sur la cellule B4 : Excel écrit la référence tout seul.
  3. Validez : Synthèse affiche 720. Le point d'exclamation sépare le nom de la feuille et la cellule.
  4. Si le nom de la feuille contient un espace, Excel l'entoure d'apostrophes.
