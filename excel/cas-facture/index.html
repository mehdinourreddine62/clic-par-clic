Résumé écrit des étapes
  1. Une facture : seuls les codes et les quantités sont saisis. Le tarif, à droite, fournit le reste.
  2. RECHERCHEV va chercher la désignation de chaque code dans le tarif, figé avec des $.
  3. Même formule pour le prix : seul le numéro de colonne change, 3 au lieu de 2.
  4. Le total de chaque ligne : le prix unitaire multiplié par la quantité.
  5. SOMME additionne les lignes : 769 € hors taxe.
  6. Une remise de 10 % à partir de 500 € : SI ne l'applique que si le seuil est atteint.
  7. Le net hors taxe : le total moins la remise.
  8. La TVA à 20 % se calcule sur le net hors taxe.
  9. Le total TTC : le net hors taxe plus la TVA. C'est la somme à payer.
  10. Sélectionnez la facture, puis Zone d'impression › Définir : le tarif ne sera pas imprimé.
  11. L'aperçu ne montre que la facture, sur une seule page.
  12. Tout est relié : changez une quantité, et remise, TVA et total TTC se recalculent.

Comment faire une facture sur Excel ?

Une facture Excel bien construite ne demande de saisir que les codes produits et les quantités : RECHERCHEV va chercher la désignation et le prix dans un tarif, puis des formules simples calculent les totaux, la remise, la TVA et le total TTC. Tout se recalcule dès qu'une quantité change.

Exemple

=RECHERCHEV(A2;$H$2:$J$6;3;FAUX)

Cherche le code de A2 dans le tarif et renvoie la 3e colonne, le prix. Les $ figent le tarif pour la recopie.

Erreurs fréquentes

  • #N/A dans la désignationLe code n'existe pas dans le tarif, ou il contient un espace en trop.
  • Une TVA calculée avant la remiseAppliquez la remise d'abord : la TVA porte sur le net hors taxe.
  • Le tarif imprimé avec la factureDéfinissez une zone d'impression limitée à la facture.

Questions fréquentes

Comment mettre le tarif sur une autre feuille ?

Écrivez la plage avec le nom de la feuille, par exemple Tarif!$A$2:$C$6, ou nommez-la.

Comment éviter #N/A sur les lignes vides ?

Entourez avec SI.NON.DISP(…;"") ou testez si le code est vide.

Faut-il arrondir la TVA ?

Pour une facture, oui : =ARRONDI(E9*C10;2).
