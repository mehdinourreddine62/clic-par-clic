Corriger #REF!

Comprendre ce qui se passe quand on supprime une cellule utilisée.

fx

La colonne Résultat soustrait les frais des ventes.

Clavier : ← → pour changer d'étape, Espace pour lancer ou mettre en pause.

Syntaxe Ctrl + Z, tout de suite
Cause
La formule pointe vers une cellule supprimée
Réflexe
Annuler immédiatement avec Ctrl + Z
Prévention
Vérifier les dépendants avant de supprimer
Résumé écrit des étapes
  1. La colonne Résultat soustrait les frais des ventes.
  2. Supprimons la colonne Frais, que la formule utilise.
  3. #REF! : la formule pointe vers une cellule qui n'existe plus.
  4. Annulez tout de suite avec Ctrl + Z. Avant de supprimer, vérifiez qu'aucune formule n'en dépend.
