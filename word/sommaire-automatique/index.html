Résumé écrit des étapes
  1. Les titres utilisent déjà les styles Titre 1, 2 et 3, et sont numérotés : c'est la base du sommaire automatique.
  2. Cliquez sur la page prévue pour le sommaire, juste après la page de garde.
  3. Références › Table des matières : Word construit le sommaire à partir des titres, avec les numéros de page.
  4. Ajoutez une partie dans le document : elle est numérotée, mais le sommaire ne change pas encore.
  5. Cliquez sur « Mettre à jour la table » : la nouvelle partie apparaît, avec sa page.
  6. Un Ctrl + clic sur une ligne du sommaire mène directement à la partie correspondante.

Comment faire un sommaire automatique dans Word ?

Le sommaire automatique, ou table des matières, se construit à partir des titres qui utilisent les styles Titre 1, Titre 2 et Titre 3. Il indique la page de chaque partie et se met à jour en un clic quand le document change.

Le chemin dans Word

Références › Table des matières › Table automatique 1

Placez d'abord le curseur à l'endroit voulu, en général sur la page qui suit la page de garde.

Erreurs fréquentes

  • Un titre manque dans le sommaireIl n'utilise pas de style de titre : appliquez Titre 1 ou Titre 2, puis mettez la table à jour.
  • Des numéros de page fauxLa table n'a pas été mise à jour après les dernières modifications.
  • « Aucune entrée de table des matières n'a été trouvée »Aucun titre du document n'utilise un style de titre.

Questions fréquentes

Comment mettre à jour le sommaire ?

Références › Mettre à jour la table, puis « Mettre à jour toute la table » pour prendre en compte les nouveaux titres.

Comment n'afficher que deux niveaux ?

Références › Table des matières › Table des matières personnalisée, puis réglez « Afficher les niveaux » sur 2.

Comment supprimer le sommaire ?

Références › Table des matières › Supprimer la table des matières.
