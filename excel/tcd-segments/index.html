Résumé écrit des étapes
  1. Voici les ventes par vendeur. Un segment va permettre de les filtrer d'un clic.
  2. Insérer un segment, cochez Région : un panneau de boutons apparaît.
  3. Cliquez sur Nord : le tableau se filtre aussitôt.
  4. Un autre clic change de région. Le bouton coloré rappelle toujours quel filtre est actif.
  5. Le petit entonnoir en haut du segment efface le filtre.
