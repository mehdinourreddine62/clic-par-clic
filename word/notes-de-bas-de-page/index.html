Notes de bas de page

Ajouter une précision en bas de page, numérotée automatiquement.

Une note de bas de page apporte une précision sans alourdir la phrase : Word la numérote pour vous.

Clavier : ← → pour changer d'étape, Espace pour lancer ou mettre en pause.

Résumé écrit des étapes
  1. Une note de bas de page apporte une précision sans alourdir la phrase : Word la numérote pour vous.
  2. Cliquez après le mot, puis Références › Insérer une note de bas de page, et tapez la note en bas de page.
  3. Ajoutez une note plus haut : elle prend le numéro 1, et la précédente devient la note 2.
  4. Pour supprimer une note, sélectionnez son numéro dans le texte et appuyez sur Suppr : les autres se renumérotent.

Comment faire une note de bas de page dans Word ?

La note de bas de page place un petit numéro dans le texte et la précision correspondante en bas de la même page. Word gère la numérotation : si vous ajoutez, déplacez ou supprimez une note, toutes les autres se renumérotent.

Le chemin dans Word

Références › Insérer une note de bas de page

Cliquez d'abord juste après le mot concerné, puis tapez le texte de la note.

Erreurs fréquentes

  • Une note supprimée en bas de page qui laisse son numéroSupprimez le numéro dans le texte, pas la note en bas : Word efface les deux.
  • Des numéros tapés à la main en exposantIls ne se recalculent pas : utilisez Insérer une note de bas de page.

Questions fréquentes

Quelle différence avec une note de fin ?

La note de fin se place à la fin du document au lieu du bas de la page.

Comment recommencer la numérotation à chaque chapitre ?

Cliquez sur la petite flèche du groupe Notes de bas de page, puis « Recommencer à chaque section ».

Comment retrouver l'appel d'une note ?

Double-cliquez sur le numéro de la note en bas de page : Word revient à l'endroit du texte.
