Saisir plus vite

Date du jour, recopie et remplissage en une combinaison de touches.

fx

Ctrl + ; insère la date du jour.

Cette leçon vous a aidé ?

Clavier : ← → pour changer d'étape, Espace pour lancer ou mettre en pause.

Syntaxe Ctrl + ;
Ctrl + ;
Insère la date du jour
Ctrl + B
Recopie la cellule du dessus
Ctrl + Entrée
Remplit toute la sélection
Alt + Entrée
Va à la ligne dans la cellule
Résumé écrit des étapes
  1. Ctrl + ; insère la date du jour.
  2. Ctrl + B recopie la cellule du dessus.
  3. Sélectionnez plusieurs cellules, tapez, puis Ctrl + Entrée : toutes sont remplies d'un coup.
  4. Alt + Entrée permet d'aller à la ligne à l'intérieur d'une cellule.
