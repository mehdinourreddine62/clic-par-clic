Corriger #DIV/0!

Comprendre et supprimer l'erreur de division par zéro.

fx

#DIV/0! signifie « division par zéro ».

Clavier : ← → pour changer d'étape, Espace pour lancer ou mettre en pause.

Syntaxe =SI(C2=0;"";B2/C2)
Cause
Le diviseur est vide ou vaut 0
Solution 1
Compléter la donnée manquante
Solution 2
Tester le diviseur avec SI
Résumé écrit des étapes
  1. #DIV/0! signifie « division par zéro ».
  2. La cause est toujours la même : le diviseur est vide ou vaut 0. Ici, Bruno n'a pas d'objectif.
  3. Première solution : compléter la donnée manquante.
  4. Seconde solution : tester le diviseur avec SI, pour laisser la cellule vide tant qu'il manque.
