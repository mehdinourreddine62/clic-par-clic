Alerte d'erreur
Le message affiché quand la saisie est refusée
Message de saisie
L'aide affichée quand on clique sur la cellule
Résumé écrit des étapes
  1. Tapez une valeur absente de la liste : Excel la refuse.
  2. Ce message est peu clair. Dans l'onglet « Alerte d'erreur », écrivez le vôtre.
  3. La personne qui remplit le fichier comprend tout de suite quoi faire.
  4. L'onglet « Message de saisie » affiche une aide dès qu'on clique sur la cellule.
