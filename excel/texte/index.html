TEXTE

Afficher une date dans le format de son choix.

fx

TEXTE affiche une date dans le format demandé.

Clavier : ← → pour changer d'étape, Espace pour lancer ou mettre en pause.

Syntaxe =TEXTE(date; "format")
j
Le jour : jj donne 13, jjjj donne vendredi
m
Le mois : mm donne 11, mmmm donne novembre
a
L'année : aa donne 26, aaaa donne 2026
Résumé écrit des étapes
  1. TEXTE affiche une date dans le format demandé.
  2. j pour le jour, m pour le mois, a pour l'année. Plus il y a de lettres, plus le résultat est détaillé.
