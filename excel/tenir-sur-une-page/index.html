Cette leçon vous a aidé ?

Clavier : ← → pour changer d'étape, Espace pour lancer ou mettre en pause.

Syntaxe Mise en page › Largeur : 1 page

Laisse le tableau continuer sur plusieurs pages
Résumé écrit des étapes
  1. Le tableau est trop large : les dernières colonnes partent sur une deuxième page.
  2. Première solution : Orientation › Paysage, pour gagner en largeur.
  3. Seconde solution : régler la largeur sur « 1 page ». Excel réduit le tableau pour qu'il tienne.
  4. Regardez toujours l'aperçu avant d'imprimer : trop réduit, le texte devient illisible.

Comment faire tenir un tableau Excel sur une page à l'impression ?

Quand un tableau est trop large, les dernières colonnes partent sur une seconde page. Deux solutions : passer en orientation paysage, ou régler la largeur sur « 1 page » dans l'onglet Mise en page, pour qu'Excel réduise le tableau juste assez. Vérifiez toujours l'aperçu avant d'imprimer.

Exemple

Mise en page › Largeur : 1 page

Laissez la hauteur sur Automatique : le tableau peut continuer sur plusieurs pages, mais tient en largeur.

Erreurs fréquentes

  • Un texte minuscule à l'impressionLe tableau est trop réduit : passez en paysage ou masquez des colonnes inutiles.
  • Une page vide imprimée en plusUne cellule lointaine contient une mise en forme : définissez une zone d'impression.

Questions fréquentes

Où voir l'aperçu ?

Fichier › Imprimer, ou Ctrl + P.

Existe-t-il une option à l'impression ?

Oui : dans Ctrl + P, « Ajuster la feuille à une page » ou « Ajuster toutes les colonnes à une page ».

Comment répéter la ligne de titres sur chaque page ?

Mise en page › Imprimer les titres › Lignes à répéter en haut.
