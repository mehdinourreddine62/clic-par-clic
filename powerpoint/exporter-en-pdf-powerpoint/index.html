Résumé écrit des étapes
  1. Fichier › Exporter › Créer un document PDF/XPS.
  2. Choisissez le dossier et donnez un nom clair au fichier ; le type PDF est déjà choisi.
  3. Cliquez sur Publier : le PDF s'ouvre, une page par diapositive, sans les notes.
  4. Envoyez ce PDF au jury, et gardez-le sur une clé USB en secours le jour de l'oral.

Comment enregistrer un PowerPoint en PDF ?

Fichier › Exporter › Créer un document PDF/XPS ouvre une fenêtre d'enregistrement : choisissez le dossier, le nom du fichier, puis cliquez sur Publier. Chaque diapositive devient une page du PDF ; les notes n'y figurent pas. Le bouton Options permet de publier plusieurs diapositives par page ou les pages de notes.

Erreurs fréquentes

  • Les animations ont disparuUn PDF est figé : chaque diapositive est affichée dans son état final.
  • Le fichier est trop lourd pour un courrielChoisissez Optimiser pour : Taille minimale, ou compressez les images avant.

Questions fréquentes

Comment mettre plusieurs diapositives par page ?

Dans la fenêtre, Options › Publier : Documents, puis le nombre par page.

Comment inclure les notes ?

Options › Publier : Pages de notes.

Peut-on présenter à partir du PDF ?

Oui, en plein écran dans le lecteur PDF, mais sans animations ni mode Présentateur.
