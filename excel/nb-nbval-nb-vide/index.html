NB, NBVAL et NB.VIDE

Compter les nombres, les cellules remplies ou les cellules vides.

fx

NB compte uniquement les cellules qui contiennent un nombre.

Clavier : ← → pour changer d'étape, Espace pour lancer ou mettre en pause.

Syntaxe =NB(plage)
NB
Compte les cellules contenant un nombre
NBVAL
Compte toutes les cellules remplies
NB.VIDE
Compte les cellules vides
Résumé écrit des étapes
  1. NB compte uniquement les cellules qui contiennent un nombre.
  2. NBVAL compte toutes les cellules remplies, texte compris.
  3. NB.VIDE compte les cellules vides.
