Trier et filtrer

Classer une liste et n'afficher que certaines lignes.

fx

Cliquez dans la colonne Prix, puis sur Trier : les lignes entières se réorganisent, du moins cher au plus cher.

Cette leçon vous a aidé ?

Clavier : ← → pour changer d'étape, Espace pour lancer ou mettre en pause.

Syntaxe Données › Trier · Données › Filtrer
Trier
Réorganise les lignes entières
Filtrer
Masque les lignes qui ne correspondent pas, sans les supprimer
Résumé écrit des étapes
  1. Cliquez dans la colonne Prix, puis sur Trier : les lignes entières se réorganisent, du moins cher au plus cher.
  2. Le bouton Filtrer ajoute une flèche à côté de chaque titre.
  3. Cliquez sur la flèche et cochez « Écriture » : les autres lignes sont masquées, pas supprimées.
  4. Effacez le filtre pour tout retrouver.

Comment trier et filtrer un tableau dans Excel ?

Trier réorganise les lignes entières d'un tableau, par exemple du moins cher au plus cher. Filtrer masque temporairement les lignes qui ne correspondent pas à un choix, sans les supprimer. Les deux commandes se trouvent dans l'onglet Données.

Exemple

Données › Trier · Données › Filtrer

Cliquez dans une cellule du tableau avant : Excel détecte tout le tableau.

Erreurs fréquentes

  • Une seule colonne triée, les lignes mélangéesSeule la colonne était sélectionnée : cliquez dans une seule cellule, puis triez.
  • Des lignes semblent disparuesUn filtre est actif : Données › Effacer pour tout réafficher.

Questions fréquentes

Comment trier sur plusieurs colonnes ?

Données › Trier, puis « Ajouter un niveau » : par catégorie, puis par prix.

Comment voir qu'un filtre est actif ?

La flèche de la colonne filtrée affiche un entonnoir, et les numéros de ligne passent en bleu.

Quel raccourci pour filtrer ?

Ctrl + Maj + L active ou retire les filtres.
