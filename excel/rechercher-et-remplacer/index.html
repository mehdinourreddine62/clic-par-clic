Rechercher et remplacer

Corriger le même texte partout, en une seule fois.

Ctrl + F recherche un texte dans toute la feuille.

Clavier : ← → pour changer d'étape, Espace pour lancer ou mettre en pause.

Syntaxe Ctrl + H
Ctrl + F
Rechercher
Ctrl + H
Remplacer
Remplacer tout
Corrige toutes les cellules concernées
Résumé écrit des étapes
  1. Ctrl + F recherche un texte dans toute la feuille.
  2. Ctrl + H ouvre Remplacer : indiquez l'ancien texte et le nouveau.
  3. « Remplacer tout » corrige toutes les cellules d'un coup.
  4. Sélectionnez d'abord une colonne pour limiter le remplacement à cette zone.
