LAMBDA : créer sa propre fonction

Enregistrer un calcul sous un nom et l'utiliser comme une fonction d'Excel.

fx

LAMBDA crée une fonction : ici, elle ajoute 20 % de TVA. On la teste directement sur A2.

Clavier : ← → pour changer d'étape, Espace pour lancer ou mettre en pause.

Syntaxe =LAMBDA(paramètre; calcul)
paramètre
La valeur que la fonction recevra
calcul
Ce que la fonction en fait
Gestionnaire de noms
Là où l'on enregistre la fonction
Version
Microsoft 365
Résumé écrit des étapes
  1. LAMBDA crée une fonction : ici, elle ajoute 20 % de TVA. On la teste directement sur A2.
  2. Pour la réutiliser, enregistrez-la dans le Gestionnaire de noms, sous le nom TTC.
  3. Elle s'utilise ensuite comme n'importe quelle fonction d'Excel, partout dans le classeur.
  4. Pour changer la règle, modifiez-la une seule fois dans le Gestionnaire de noms : toutes les cellules suivent.
