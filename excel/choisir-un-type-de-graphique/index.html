Choisir le bon type

Histogramme, courbe, secteurs ou barres : à chaque question son graphique.

Pour comparer des valeurs entre elles : l'histogramme.

Cette leçon vous a aidé ? Partagez-la avec vos camarades.

Clavier : ← → pour changer d'étape, Espace pour lancer ou mettre en pause.

Syntaxe Une question, un type de graphique
Histogramme
Comparer des valeurs
Courbe
Montrer une évolution dans le temps
Secteurs
Montrer la part de chacun dans un total
Barres
Faire un classement, afficher des noms longs
Résumé écrit des étapes
  1. Pour comparer des valeurs entre elles : l'histogramme.
  2. Pour montrer une évolution dans le temps : la courbe.
  3. Pour montrer la part de chacun dans un total : les secteurs.
  4. Pour un classement, ou des noms longs : les barres horizontales.
  5. Vous pouvez changer d'avis : « Modifier le type de graphique » conserve les données.
