Résumé écrit des étapes
  1. Ces titres ont été mis en gras à la main : pour Word, ce ne sont que des paragraphes ordinaires.
  2. Cliquez dans le titre, puis sur « Titre 1 » dans la galerie des styles de l'onglet Accueil.
  3. Faites de même pour chaque grande partie : elles prennent toutes exactement la même apparence.
  4. Une sous-partie reçoit le style « Titre 2 », un cran en dessous.
  5. Affichage › Volet de navigation : le plan du document apparaît, construit à partir des styles.
  6. Modifiez le style une seule fois : tous les titres du document changent ensemble.

Pourquoi utiliser les styles de titres dans Word ?

Un titre mis en gras à la main reste un paragraphe ordinaire pour Word. Avec les styles Titre 1, Titre 2 et Titre 3, Word connaît le plan du document : il peut construire le sommaire automatique, afficher le volet de navigation et numéroter les parties.

Le chemin dans Word

Accueil › Styles › Titre 1

Cliquez dans le titre, puis sur le style voulu dans la galerie : inutile de sélectionner tout le texte.

Erreurs fréquentes

  • Un titre absent du sommaireIl a été mis en forme à la main : appliquez-lui le style Titre 1 ou Titre 2.
  • Des titres qui ne se ressemblent pasCertains ont été retouchés à la main : réappliquez le style pour les uniformiser.

Questions fréquentes

Comment voir le plan du document ?

Affichage › Volet de navigation : la liste des titres s'affiche à gauche, et un clic mène à la partie.

Existe-t-il un raccourci clavier ?

Oui : Ctrl + Alt + 1 applique Titre 1, Ctrl + Alt + 2 Titre 2 et Ctrl + Alt + 3 Titre 3.

Je n'aime pas l'apparence des titres, que faire ?

Modifiez le style lui-même : tous les titres concernés changent en une seule fois.
