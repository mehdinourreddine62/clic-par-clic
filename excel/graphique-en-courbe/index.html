Courbe

Suivre une évolution dans le temps.

fx

La courbe relie les points dans l'ordre : elle montre une évolution.

Cette leçon vous a aidé ? Partagez-la avec vos camarades.

Clavier : ← → pour changer d'étape, Espace pour lancer ou mettre en pause.

Résumé écrit des étapes
  1. La courbe relie les points dans l'ordre : elle montre une évolution.
  2. L'axe horizontal doit suivre le temps : jours, mois ou années, dans l'ordre.
  3. La pente raconte l'histoire : ici, la fréquentation décolle à partir d'avril.
  4. Un creux ou un pic saute aux yeux, bien plus que dans un tableau de chiffres.
