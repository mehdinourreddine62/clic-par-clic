Le masque des diapositives : logo, police et couleurs

Modifier le masque pour placer un logo, changer la police et les couleurs de toutes les diapositives d'un coup.

Affichage › Masque des diapositives : le modèle commun à toutes les diapositives s'affiche.

Cette leçon vous a aidé ?

Clavier : ← → pour changer d'étape, Espace pour lancer ou mettre en pause.

Résumé écrit des étapes
  1. Affichage › Masque des diapositives : le modèle commun à toutes les diapositives s'affiche.
  2. La grande miniature en haut est le masque : ce que vous y changez s'applique partout.
  3. Insertion › Images : ajoutez le logo de l'entreprise, puis placez-le dans un coin.
  4. Masque des diapositives › Polices : une seule police pour tous les titres et textes.
  5. Couleurs change la palette : le fond, les titres et les formes suivent.
  6. Fermer le mode Masque : toutes les diapositives ont maintenant le logo, la police et les couleurs.

Comment mettre un logo sur toutes les diapositives PowerPoint ?

Le masque des diapositives est le modèle commun à toute la présentation. Ouvrez-le par Affichage › Masque des diapositives, cliquez sur la grande miniature du haut, puis insérez le logo, changez les polices ou les couleurs : chaque modification s'applique à toutes les diapositives. Fermez ensuite le mode Masque pour revenir à votre travail.

Erreurs fréquentes

  • Le logo n'apparaît que sur une diapositiveIl a été inséré sur une diapositive normale : supprimez-le et insérez-le sur le masque.
  • Le logo apparaît seulement sur certaines dispositionsIl a été placé sur une disposition (petite miniature) et non sur le masque (grande miniature du haut).

Questions fréquentes

Peut-on déplacer le logo sur une diapositive ?

Non, il est verrouillé : c'est voulu. Pour le modifier, rouvrez le masque.

Comment masquer le logo sur la diapositive de titre ?

Dans le masque, sélectionnez la disposition Titre et cochez Masquer les graphiques d'arrière-plan.

Le masque change-t-il le texte déjà écrit ?

Il change son apparence (police, couleur), jamais son contenu.
