Résumé écrit des étapes
  1. Quelques raccourcis font gagner beaucoup de temps : voici les plus utiles, un par un.
  2. Ctrl + A sélectionne tout le texte du document.
  3. Ctrl + G met la sélection en gras ; Ctrl + I en italique, Ctrl + U la souligne.
  4. Ctrl + Z annule la dernière action ; Ctrl + Y la rétablit.
  5. Ctrl + Alt + 1 applique le style Titre 1 ; Ctrl + Alt + 2, le style Titre 2.
  6. F7 lance la vérification de l'orthographe : le mot souligné en rouge est corrigé.
  7. Ctrl + Entrée insère un saut de page : la suite commence sur une nouvelle page.
  8. Ctrl + S enregistre le document : prenez l'habitude d'appuyer souvent.

Quels sont les raccourcis clavier Word les plus utiles ?

Les raccourcis évitent d'aller chercher les boutons dans le ruban. Les plus utiles pour un rapport : Ctrl + A pour tout sélectionner, Ctrl + G, I et U pour le gras, l'italique et le souligné, Ctrl + Z pour annuler, Ctrl + S pour enregistrer, Ctrl + Entrée pour un saut de page et F7 pour l'orthographe.

À retenir

Ctrl + S

Enregistrez souvent : un rapport perdu à la veille du rendu, c'est des heures de travail.

Erreurs fréquentes

  • Ctrl + B ne met pas en grasDans Word en français, le gras est Ctrl + G (G comme gras).
  • Ctrl + Z a annulé trop de chosesCtrl + Y rétablit ce qui vient d'être annulé.

Questions fréquentes

Comment rechercher un mot ?

Ctrl + F ouvre la recherche dans le volet de navigation.

Comment remplacer un mot partout ?

Ctrl + H ouvre la fenêtre Rechercher et remplacer.

Comment changer la casse (majuscules, minuscules) ?

Sélectionnez le texte et appuyez sur Maj + F3, plusieurs fois si besoin.
