ARRONDI

Garder le nombre de décimales voulu.

fx

Le 2 indique le nombre de décimales à garder.

Clavier : ← → pour changer d'étape, Espace pour lancer ou mettre en pause.

Syntaxe =ARRONDI(nombre; décimales)
nombre
La valeur à arrondir
décimales
2 pour les centimes, 0 pour un entier, -1 pour la dizaine
Résumé écrit des étapes
  1. Le 2 indique le nombre de décimales à garder.
  2. Avec 0, on obtient un entier. À partir de 0,5, Excel arrondit vers le haut.
  3. Un nombre négatif arrondit à la dizaine (-1) ou à la centaine (-2).
