Résumé écrit des étapes
  1. La courbe monte et descend d'une semaine à l'autre : difficile de voir la direction générale.
  2. Dans les éléments de graphique, cochez « Courbe de tendance ».
  3. La droite en pointillés résume le mouvement : ici, une hausse régulière.
  4. Elle se recalcule avec les données. Attention : une tendance décrit le passé, elle ne garantit pas la suite.

Comment ajouter une courbe de tendance dans Excel ?

Une courbe de tendance résume la direction générale d'une série qui monte et descend : elle trace une droite (ou une courbe) qui lisse les variations. Sélectionnez le graphique, puis Éléments de graphique (le bouton +) › Courbe de tendance. Elle se recalcule quand les données changent.

Visiteurs sur 8 semaines : 210, 260, 230, 300, 280, 340, 330, 390. Malgré les creux, la droite en pointillés montre une hausse régulière.

Erreurs fréquentes

  • L'option est griséeElle n'existe pas pour les graphiques en secteurs ni pour les histogrammes empilés : utilisez une courbe ou un nuage de points.
  • La tendance est prise pour une prévisionElle décrit le passé ; prolonger la droite reste une hypothèse.

Questions fréquentes

Comment afficher l'équation ?

Clic droit sur la courbe de tendance › Format › cochez Afficher l'équation sur le graphique.

Quel type choisir ?

Linéaire dans la plupart des cas ; exponentielle si la croissance s'accélère.

Comment prolonger la tendance ?

Dans Format de la courbe de tendance, réglez Prévision : en avant de quelques périodes.
