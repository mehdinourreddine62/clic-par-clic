Résumé écrit des étapes
  1. Par défaut, un tableau croisé additionne les nombres.
  2. Clic droit sur une valeur, « Synthétiser les valeurs par », Nombre : on compte les ventes au lieu de les additionner.
  3. Avec Moyenne, on obtient la vente moyenne de chaque région.
  4. Pour afficher deux calculs côte à côte, glissez le champ une seconde fois dans Valeurs.
