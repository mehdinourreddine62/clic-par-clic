Créer un tableau croisé dynamique

Résumer un tableau en quelques clics, sans formule.

fx

Cliquez dans vos données, puis Insertion › Tableau croisé dynamique.

Clavier : ← → pour changer d'étape, Espace pour lancer ou mettre en pause.

Syntaxe Insertion › Tableau croisé dynamique
Champs
Les colonnes de votre tableau
Lignes
Ce que l'on veut regrouper
Valeurs
Ce que l'on veut calculer
Résumé écrit des étapes
  1. Cliquez dans vos données, puis Insertion › Tableau croisé dynamique.
  2. La liste des champs s'ouvre : chaque champ correspond à une colonne de votre tableau.
  3. Cochez Région : elle arrive dans la zone Lignes, une ligne par région.
  4. Cochez Montant : il va dans Valeurs, et Excel additionne les ventes de chaque région.
  5. 430 est la somme des quatre ventes du Nord, sans écrire une seule formule.
