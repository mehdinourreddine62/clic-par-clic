Résumé écrit des étapes
  1. Un clic sélectionne une cellule.
  2. Cliquez et faites glisser pour sélectionner une plage. Celle-ci se note A2:B3.
  3. Un clic sur la lettre d'une colonne sélectionne toute la colonne.
  4. Un clic sur un numéro sélectionne toute la ligne.
  5. Maintenez Ctrl pour ajouter une seconde sélection, même éloignée.
  6. Ctrl + A sélectionne tout le tableau d'un coup.
