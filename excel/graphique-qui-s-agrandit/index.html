Un graphique qui s'agrandit tout seul

Faire suivre le graphique quand on ajoute des données.

fx

Un graphique classique dessine une plage fixe : ici, de janvier à avril.

Clavier : ← → pour changer d'étape, Espace pour lancer ou mettre en pause.

Syntaxe Mettre les données sous forme de tableau
Plage classique
Le graphique ne voit pas les nouvelles lignes
Tableau
Le graphique suit le tableau quand il s'agrandit
Résumé écrit des étapes
  1. Un graphique classique dessine une plage fixe : ici, de janvier à avril.
  2. Ajoutez un mois sous les données : le graphique l'ignore.
  3. Mettez les données sous forme de tableau : le graphique prend maintenant tout le tableau.
  4. Ajoutez une ligne : le tableau s'étend, et le graphique suit tout seul.
