Graphiques Intermédiaire

Plusieurs séries

Comparer deux années côte à côte dans le même graphique.

fx

Avec une seule colonne de valeurs, le graphique contient une seule série.

Clavier : ← → pour changer d'étape, Espace pour lancer ou mettre en pause.

Syntaxe Une colonne de valeurs = une série
Série
Une colonne de valeurs, dessinée dans une couleur
Légende
Reprend le titre de chaque colonne
Limite
Au-delà de trois ou quatre séries, le graphique se brouille
Résumé écrit des étapes
  1. Avec une seule colonne de valeurs, le graphique contient une seule série.
  2. Sélectionnez aussi la deuxième colonne : chaque trimestre reçoit deux barres, côte à côte.
  3. La légende reprend les titres des colonnes pour dire quelle couleur correspond à quelle année.
  4. La comparaison est immédiate : seul le deuxième trimestre a reculé.
