Créer une liste déroulante

Faire choisir une valeur dans une liste, sans faute de frappe.

Résumé écrit des étapes
  1. Sélectionnez les cellules à contrôler, puis ouvrez « Validation des données ».
  2. Choisissez « Liste » et tapez les choix, séparés par des points-virgules.
  3. Une flèche apparaît dans la cellule : un clic ouvre la liste.
  4. Choisissez une valeur : plus de faute de frappe, tout le monde écrit la même chose.
  5. La liste fonctionne dans toutes les cellules sélectionnées au départ.

À quoi sert une liste déroulante ?

Une liste déroulante oblige à choisir une valeur parmi des choix prévus : un statut, un service, une ville. Elle évite les fautes de frappe et garantit que tout le monde écrit la même chose. Elle se crée avec la validation des données.

Exemple

Données › Validation des données › Liste

Dans Source, tapez les choix séparés par des points-virgules (À faire;En cours;Terminé), ou désignez une plage qui les contient.

Erreurs fréquentes

  • Pas de flèche dans la celluleLa case « Liste déroulante dans la cellule » est décochée dans la validation.
  • Les nouveaux choix n'apparaissent pasLa source est une plage fixe. Mettez les choix sous forme de tableau pour qu'elle s'agrandisse.
  • Une valeur refuséeC'est le but : seules les valeurs de la liste sont acceptées.

Questions fréquentes

Comment modifier une liste déroulante ?

Sélectionnez les cellules et rouvrez Données › Validation des données.

Comment supprimer une liste déroulante ?

Données › Validation des données › Effacer tout.

Peut-on prendre les choix sur une autre feuille ?

Oui : indiquez la plage dans Source, par exemple =Listes!$A$2:$A$10.
