Résumé écrit des étapes
  1. Le bouton monétaire ajoute le symbole € et deux décimales.
  2. Le bouton % affiche 0,15 sous la forme 15 %.
  3. Le séparateur de milliers rend les grands nombres plus lisibles.
  4. Le format change seulement l'affichage : la barre de formule montre toujours la vraie valeur.

Comment changer le format des nombres dans Excel ?

Le format de nombre change l'apparence d'une valeur sans modifier la valeur elle-même : 0,15 peut s'afficher 15 %, 1249,5 devenir 1 249,50 €. Les boutons du groupe Nombre, dans l'onglet Accueil, donnent les formats monétaire, pourcentage et séparateur de milliers.

Exemple

Accueil › Nombre › Format monétaire

1249,5 s'affiche 1 249,50 € ; la barre de formule garde 1249,5.

Erreurs fréquentes

  • Un pourcentage qui affiche 1500 %La cellule contenait 15 au lieu de 0,15 : tapez 15 % directement, ou 0,15.
  • Des ##### dans la celluleLa colonne est trop étroite pour le nombre formaté : élargissez-la.

Questions fréquentes

Comment afficher plus de décimales ?

Boutons « Ajouter une décimale » et « Réduire les décimales » du groupe Nombre.

Comment créer un format personnalisé ?

Clic droit › Format de cellule › Personnalisée, par exemple 0" kg".

Un nombre reste aligné à gauche, pourquoi ?

Il est stocké comme texte : convertissez-le en nombre.
