Résumé écrit des étapes
  1. Les secteurs montrent comment un total se répartit.
  2. Affichez les pourcentages avec les étiquettes de données : Excel les calcule tout seul.
  3. Il fonctionne bien avec peu de parts, dont une domine : le loyer pèse la moitié du budget.
  4. Au-delà de cinq ou six parts, il devient illisible.
  5. Préférez alors des barres : les mêmes données redeviennent comparables.
