Insérer et rogner une image

Insérer une photo depuis l'ordinateur, la rogner avec les poignées noires et lui donner un style.

Insertion › Images › Cet appareil : choisissez la photo puis cliquez sur Insérer.

Cette leçon vous a aidé ?

Clavier : ← → pour changer d'étape, Espace pour lancer ou mettre en pause.

Résumé écrit des étapes
  1. Insertion › Images › Cet appareil : choisissez la photo puis cliquez sur Insérer.
  2. L'image sélectionnée, l'onglet Format de l'image apparaît dans le ruban.
  3. Format de l'image › Rogner : des poignées noires apparaissent sur les bords.
  4. Faites glisser une poignée noire vers l'intérieur pour couper ce qui ne sert pas.
  5. Appuyez sur Échap ou cliquez à côté : seule la partie gardée reste visible.
  6. Format de l'image › Styles : un cadre et une ombre donnent du relief à la photo.

Comment rogner une image dans PowerPoint ?

Insérez la photo par Insertion › Images › Cet appareil. Une fois l'image sélectionnée, l'onglet Format de l'image apparaît : le bouton Rogner affiche des poignées noires sur les bords et aux coins. Faites-les glisser vers l'intérieur pour couper ce qui est inutile, puis appuyez sur Échap. Le groupe Styles d'images ajoute un cadre ou une ombre.

Bon réflexe

Format de l'image › Rogner

Rognez plutôt que d'écraser l'image : tirer une poignée blanche de côté la déforme.

Erreurs fréquentes

  • L'image est déforméeVous avez tiré une poignée de côté : Ctrl + Z, puis redimensionnez par un coin.
  • L'onglet Format de l'image n'apparaît pasL'image n'est pas sélectionnée : cliquez dessus.

Questions fréquentes

Comment récupérer la partie coupée ?

Recliquez sur Rogner et tirez les poignées vers l'extérieur : rien n'est perdu.

Comment rogner en cercle ?

Format de l'image › flèche de Rogner › Rogner à la forme › Ellipse.

Comment alléger le fichier ?

Format de l'image › Compresser les images.
