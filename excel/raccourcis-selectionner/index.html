Sélectionner au clavier

Sélectionner une plage, une colonne ou une ligne avec les touches.

fx

Maj + flèche étend la sélection d'une cellule.

Clavier : ← → pour changer d'étape, Espace pour lancer ou mettre en pause.

Syntaxe Maj + flèche
Maj + flèche
Étend la sélection d'une cellule
Ctrl + Maj + flèche
Étend jusqu'au bord des données
Ctrl + Espace
Toute la colonne
Maj + Espace
Toute la ligne
Résumé écrit des étapes
  1. Maj + flèche étend la sélection d'une cellule.
  2. Ajoutez Ctrl pour aller d'un coup jusqu'à la dernière ligne.
  3. Ctrl + Espace sélectionne toute la colonne.
  4. Maj + Espace sélectionne toute la ligne.
