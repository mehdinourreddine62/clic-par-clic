Protéger par mot de passe

Demander un mot de passe à l'ouverture du classeur.

fx

Ouvrez Fichier › Informations › Protéger le classeur.

Clavier : ← → pour changer d'étape, Espace pour lancer ou mettre en pause.

Syntaxe Fichier › Informations › Protéger le classeur
Chiffrer avec mot de passe
Le fichier ne s'ouvre plus sans le mot de passe
Attention
Un mot de passe oublié ne se récupère pas
Résumé écrit des étapes
  1. Ouvrez Fichier › Informations › Protéger le classeur.
  2. « Chiffrer avec mot de passe » : saisissez-le deux fois, puis enregistrez.
  3. À la prochaine ouverture, Excel le demandera.
  4. Attention : un mot de passe oublié ne se récupère pas. Notez-le dans un endroit sûr.
