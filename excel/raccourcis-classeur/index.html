Enregistrer, rechercher, remplacer, imprimer et changer de feuille.

Ctrl + S enregistre le classeur. À faire souvent.

Clavier : ← → pour changer d'étape, Espace pour lancer ou mettre en pause.

Résumé écrit des étapes
  1. Ctrl + S enregistre le classeur. À faire souvent.
  2. Ctrl + F recherche un mot dans la feuille, ici « Cahier ».
  3. Ctrl + H remplace un texte par un autre, partout à la fois.
  4. Ctrl + P ouvre l'aperçu avant impression.
  5. Ctrl + Page suivante passe à la feuille suivante.
