Bien préparer ses données

Un tableau propre donne un graphique juste.

fx

Ce graphique est faussé : une ligne vide crée un trou, et le total écrase les autres barres.

Cette leçon vous a aidé ?

Clavier : ← → pour changer d'étape, Espace pour lancer ou mettre en pause.

Syntaxe Un bloc continu, avec une ligne de titres
Ligne de titres

Bloc continu

Total
À laisser hors de la sélection
Résumé écrit des étapes
  1. Ce graphique est faussé : une ligne vide crée un trou, et le total écrase les autres barres.
  2. Supprimez les lignes vides : les données doivent former un bloc continu.
  3. Laissez le total hors de la sélection : ce n'est pas une catégorie comme les autres.
  4. Gardez une ligne de titres : Excel s'en sert pour nommer les axes et la légende.
