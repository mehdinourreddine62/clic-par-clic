Résumé écrit des étapes
  1. Voici les ventes par produit, sur tout le trimestre.
  2. Insérer une chronologie, cochez Date : une frise des mois apparaît.
  3. Cliquez sur février : seules les ventes de ce mois sont comptées.
  4. Étirez la sélection pour couvrir plusieurs mois.
  5. Condition : la colonne doit contenir de vraies dates, pas du texte.
