Clavier : ← → pour changer d'étape, Espace pour lancer ou mettre en pause.

Syntaxe Glisser un champ dans la zone Filtres
Zone Filtres
Ajoute une liste au-dessus du tableau
(Tous)
Affiche toutes les données
Résumé écrit des étapes
  1. Voici les ventes par région, tous vendeurs confondus.
  2. Glissez Vendeur dans la zone Filtres : une liste apparaît au-dessus du tableau.
  3. Choisissez Alice : le tableau ne montre plus que ses ventes.
  4. Revenez sur « (Tous) » pour tout réafficher. Les données d'origine ne sont jamais modifiées.
