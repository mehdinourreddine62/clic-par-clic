Titre et étiquettes

Écrire un titre utile et afficher les valeurs.

fx

« Ventes » ne dit pas grand-chose. Double-cliquez sur le titre pour le modifier.

Clavier : ← → pour changer d'étape, Espace pour lancer ou mettre en pause.

Syntaxe Double-clic sur le titre pour le modifier
Titre
Annonce le message, pas seulement le sujet
Étiquettes de données
Affichent la valeur sur chaque barre
Axe
Peut être retiré quand les valeurs sont écrites
Résumé écrit des étapes
  1. « Ventes » ne dit pas grand-chose. Double-cliquez sur le titre pour le modifier.
  2. Un bon titre annonce le message, pas seulement le sujet.
  3. Ajoutez les étiquettes de données pour afficher les valeurs.
  4. Les valeurs étant écrites, l'axe vertical fait doublon : on peut le retirer.
