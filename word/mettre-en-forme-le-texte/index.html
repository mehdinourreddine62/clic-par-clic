Résumé écrit des étapes
  1. Le texte se met en forme dans l'onglet Accueil : police, gras, alignement, interligne.
  2. Sélectionnez des mots, puis cliquez sur G (Ctrl + G) : ils passent en gras.
  3. I (Ctrl + I) met en italique ; S (Ctrl + U) souligne.
  4. Sélectionnez les paragraphes, puis choisissez une police dans la liste, par exemple Times New Roman.
  5. Justifier aligne le texte sur les deux marges, comme dans un livre.
  6. Interligne › 1,5 : les lignes s'espacent, le texte devient plus lisible.
  7. Cliquez dans un mot en gras, sur le pinceau « Reproduire la mise en forme », puis sur d'autres mots : ils passent en gras.

Comment mettre en forme le texte dans Word ?

Sélectionnez d'abord le texte, puis utilisez l'onglet Accueil : le groupe Police pour le gras, l'italique, la police et la taille, le groupe Paragraphe pour l'alignement et l'interligne. Pour un rapport, une police lisible, un texte justifié et un interligne de 1,5 sont souvent demandés.

Le chemin dans Word

Accueil › Paragraphe › Interligne › 1,5

Sélectionnez d'abord les paragraphes concernés, ou tout le texte avec Ctrl + A.

Erreurs fréquentes

  • La mise en forme ne s'applique qu'à un motLe texte n'était pas sélectionné : sélectionnez tous les paragraphes avant de cliquer.
  • Des mises en forme différentes d'une page à l'autreModifiez plutôt le style Normal : tout le texte courant suit en une fois.

Questions fréquentes

Comment appliquer le pinceau plusieurs fois ?

Double-cliquez sur le pinceau : il reste actif jusqu'à ce que vous appuyiez sur Échap.

Comment effacer toute la mise en forme ?

Sélectionnez le texte, puis Accueil › Effacer toute la mise en forme (le A avec une gomme).

Quelle taille pour un rapport ?

Souvent 11 ou 12 points : suivez les consignes de votre établissement.
