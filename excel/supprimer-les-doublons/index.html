Résumé écrit des étapes
  1. Cette liste contient des lignes en double : Durand et Martin apparaissent deux fois.
  2. Cliquez dans la liste, puis Données › Supprimer les doublons.
  3. Excel ne garde que la première occurrence de chaque ligne et annonce le résultat.
  4. La suppression est définitive : travaillez sur une copie, ou annulez tout de suite avec Ctrl + Z.

Comment supprimer les doublons ?

La commande Supprimer les doublons retire les lignes répétées d'une liste et ne garde que la première occurrence de chacune. On choisit les colonnes qui servent à comparer les lignes.

Exemple

Données › Supprimer les doublons

Cochez les colonnes à comparer : deux lignes sont des doublons si elles sont identiques sur toutes les colonnes cochées.

Erreurs fréquentes

  • Des doublons restentDes espaces en trop rendent les valeurs différentes pour Excel. Nettoyez-les d'abord avec SUPPRESPACE.
  • Des lignes utiles ont disparuTrop peu de colonnes étaient cochées. Annulez tout de suite avec Ctrl + Z.

Questions fréquentes

Comment repérer les doublons sans les supprimer ?

Avec la mise en forme conditionnelle › Valeurs en double.

Comment obtenir une liste sans doublons à côté des données ?

Avec la fonction UNIQUE, qui laisse les données d'origine intactes.
