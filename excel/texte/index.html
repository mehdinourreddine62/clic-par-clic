Comment utiliser la fonction TEXTE dans Excel ?

TEXTE transforme un nombre ou une date en texte, dans le format de votre choix : « vendredi 13 novembre 2026 », « novembre 2026 » ou « 13/11 ». Les codes sont en français : j pour le jour, m pour le mois, a pour l'année. Plus il y a de lettres, plus le résultat est détaillé.

Exemple

=TEXTE(A2;"mmmm aaaa")

Le 13/11/2026 devient « novembre 2026 ». Avec "jjjj" : « vendredi ».

Erreurs fréquentes

  • Le format s'affiche tel quelLe format doit être entre guillemets : "jj/mm/aaaa".
  • Le résultat ne se calcule plusTEXTE renvoie du texte : gardez la date d'origine pour les calculs.

Questions fréquentes

Comment écrire une phrase avec une date ?

Assemblez avec & : ="Le "&TEXTE(A2;"jj/mm/aaaa").

Comment afficher un nombre avec 2 décimales ?

=TEXTE(B2;"0,00").

Faut-il utiliser TEXTE pour changer l'affichage ?

Non, le format de cellule suffit. TEXTE sert surtout dans une phrase ou un assemblage.
