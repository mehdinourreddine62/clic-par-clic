Combiner plusieurs filtres

Filtrer sur deux colonnes à la fois.

fx

Activez le filtre : chaque colonne peut recevoir son propre filtre.

Clavier : ← → pour changer d'étape, Espace pour lancer ou mettre en pause.

Syntaxe Un filtre par colonne, cumulés
Cumul
Chaque filtre réduit le résultat du précédent
Entonnoir
Signale une colonne filtrée
Données › Effacer
Retire tous les filtres d'un coup
Résumé écrit des étapes
  1. Activez le filtre : chaque colonne peut recevoir son propre filtre.
  2. Filtrez la région sur Nord. Un entonnoir remplace la flèche pour signaler la colonne filtrée.
  3. Ajoutez un filtre sur le montant : les deux se cumulent. Il ne reste que le Nord au-dessus de 300.
  4. Données › Effacer retire tous les filtres d'un coup, sans désactiver les flèches.
