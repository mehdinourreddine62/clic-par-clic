Régler les axes

Minimum, maximum et graduations, sans tromper le lecteur.

fx

Paris semble vendre trois fois plus que Lille. Regardez l'axe : il commence à 90.

Cette leçon vous a aidé ?

Clavier : ← → pour changer d'étape, Espace pour lancer ou mettre en pause.

Syntaxe Double-clic sur l'axe › Options d'axe
Minimum
La valeur où commence l'axe
Maximum
La valeur où il s'arrête
Unité principale
L'écart entre deux graduations
Résumé écrit des étapes
  1. Paris semble vendre trois fois plus que Lille. Regardez l'axe : il commence à 90.
  2. Remettez le minimum à 0 : les écarts retrouvent leur vraie taille.
  3. Pour un histogramme, l'axe doit partir de zéro, sinon les hauteurs trompent.
  4. L'unité principale règle l'écart entre deux graduations.
