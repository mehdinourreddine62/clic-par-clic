Corriger #N/A

Comprendre pourquoi une recherche ne trouve rien.

fx

#N/A signifie « non disponible » : la valeur cherchée est introuvable.

Clavier : ← → pour changer d'étape, Espace pour lancer ou mettre en pause.

Syntaxe =SI.NON.DISP(recherche; "Inconnu")
Cause 1
La valeur cherchée n'existe pas dans la liste
Cause 2
Un espace en trop, ou un nombre stocké comme texte
SI.NON.DISP
Remplace #N/A par le texte de votre choix
Résumé écrit des étapes
  1. #N/A signifie « non disponible » : la valeur cherchée est introuvable.
  2. Première cause : la valeur n'existe vraiment pas. P05 n'est pas dans la liste.
  3. Seconde cause, plus sournoise : un espace invisible après P02. Pour Excel, ce n'est plus le même texte.
  4. Retapez la valeur, ou nettoyez-la avec SUPPRESPACE : la recherche aboutit.
  5. Pour les vraies absences, SI.NON.DISP remplace #N/A par le texte de votre choix.
