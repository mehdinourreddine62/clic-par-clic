SERIE.JOUR.OUVRE

Trouver la date après un certain nombre de jours travaillés.

fx

Cinq jours ouvrés après le vendredi 13 : le week-end est sauté.

Clavier : ← → pour changer d'étape, Espace pour lancer ou mettre en pause.

Syntaxe =SERIE.JOUR.OUVRE(début; jours; [fériés])
début
La date de départ
jours
Le nombre de jours travaillés à ajouter
fériés
Les jours fériés à sauter
Résumé écrit des étapes
  1. Cinq jours ouvrés après le vendredi 13 : le week-end est sauté.
  2. Un jour ouvré après un vendredi, c'est le lundi suivant.
