JOINDRE.TEXTE

Assembler une plage de cellules avec un séparateur.

En anglais : TEXTJOIN · Toutes les fonctions en anglais

fx

JOINDRE.TEXTE assemble toute une plage en plaçant le séparateur entre chaque valeur.

Cette leçon vous a aidé ?

Clavier : ← → pour changer d'étape, Espace pour lancer ou mettre en pause.

Télécharger le fichier d'exerciceExcel · consignes, données de départ et solution
Syntaxe =JOINDRE.TEXTE(séparateur; ignorer_vides; plage)
séparateur
Le texte placé entre chaque valeur
ignorer_vides
VRAI pour sauter les cellules vides
plage
Les cellules à assembler
Résumé écrit des étapes
  1. JOINDRE.TEXTE assemble toute une plage en plaçant le séparateur entre chaque valeur.
  2. Avec VRAI, les cellules vides sont ignorées : pas de séparateur en double.
  3. Avec FAUX, la cellule vide laisse un trou.
