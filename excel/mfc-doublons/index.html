Résumé écrit des étapes
  1. Sélectionnez la liste, puis ouvrez Mise en forme conditionnelle.
  2. Valeurs en double : toutes les cellules qui se répètent passent en rouge.
  3. Corrigez une saisie : la couleur disparaît d'elle-même.
  4. Pour supprimer les doublons plutôt que les repérer, utilisez Données › Supprimer les doublons.

Comment repérer les doublons dans Excel ?

La mise en forme conditionnelle colore automatiquement toutes les valeurs qui apparaissent plusieurs fois dans une liste : des noms, des numéros ou des codes saisis en double. La couleur disparaît d'elle-même dès que le doublon est corrigé.

Exemple

Accueil › Mise en forme conditionnelle › Règles de mise en surbrillance › Valeurs en double

Sélectionnez la colonne d'abord, puis choisissez la couleur.

Erreurs fréquentes

  • Des doublons non repérésLes valeurs diffèrent d'un espace : nettoyez avec SUPPRESPACE.
  • Toute la feuille devient rougeLa règle s'applique à une sélection trop large : sélectionnez seulement la colonne concernée.

Questions fréquentes

Comment supprimer les doublons ?

Données › Supprimer les doublons, de préférence sur une copie.

Comment compter les doublons ?

Avec NB.SI : =NB.SI(A:A;A2)>1 indique si la valeur se répète.

Comment retirer la couleur ?

Mise en forme conditionnelle › Effacer les règles.
