Résumé écrit des étapes
  1. Sélectionnez les données, titres compris.
  2. Dans l'onglet Insertion, choisissez un type de graphique : il apparaît sur la feuille.
  3. Le graphique reste lié aux données : modifiez une valeur, la barre suit.

Comment faire un graphique dans Excel ?

Pour créer un graphique, sélectionnez vos données avec leurs titres, puis choisissez un type dans l'onglet Insertion : histogramme pour comparer, courbe pour une évolution, secteurs pour une répartition. Le graphique reste lié aux données : il se met à jour quand une valeur change.

Exemple

Insertion › Graphiques › Histogramme

Sélectionnez d'abord A1:B6, titres compris : ils deviennent les légendes et les étiquettes.

Erreurs fréquentes

  • Les titres apparaissent comme des valeursUne colonne de titres contient des nombres (des années, par exemple) : mettez-les en texte ou sélectionnez-les à part.
  • Un graphique illisibleTrop de données ou un mauvais type : un secteur ne doit pas dépasser 5 ou 6 parts.

Questions fréquentes

Comment ajouter un titre ?

Cliquez sur le graphique, puis sur le bouton + à sa droite, et cochez Titre du graphique.

Comment changer le type de graphique ?

Clic droit sur le graphique › Modifier le type de graphique.

Existe-t-il un raccourci ?

Alt + F1 crée un graphique sur la feuille à partir des données sélectionnées.
