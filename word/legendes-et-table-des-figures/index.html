Résumé écrit des étapes
  1. Dans un rapport, chaque image ou graphique porte un numéro et une légende : Word s'en charge.
  2. Cliquez sur l'image, puis Références › Insérer une légende : tapez le texte après « Figure 1 ».
  3. Faites de même pour le graphique : Word lui donne le numéro 2.
  4. Sur la page prévue, Références › Table des illustrations : la liste des figures s'insère, avec leurs pages.
  5. Ajoutez une image légendée plus haut : elle devient la figure 1, et les suivantes se renumérotent seules.
  6. Mettez la table à jour : elle reprend les trois figures, avec leurs nouveaux numéros.

Comment faire une table des figures dans Word ?

Une légende insérée par Word (« Figure 1 : … ») est numérotée automatiquement : ajoutez ou déplacez une image, les numéros suivent. La table des figures, appelée table des illustrations dans Word, liste ensuite toutes ces légendes avec leur page, comme un sommaire.

Le chemin dans Word

Références › Insérer une légende

Puis, sur la page prévue : Références › Table des illustrations.

Erreurs fréquentes

  • Des numéros tapés à la mainIls ne se décalent pas quand une figure est ajoutée : utilisez Insérer une légende.
  • Une figure absente de la tableSa légende n'a pas été insérée par Word, ou la table n'a pas été mise à jour.
  • Des tableaux mélangés aux figuresChoisissez l'étiquette « Tableau » pour leurs légendes : Word fait deux listes séparées.

Questions fréquentes

Comment mettre la légende au-dessus d'un tableau ?

Dans la fenêtre Légende, choisissez la position « Au-dessus de la sélection ».

Comment mettre à jour la table des figures ?

Cliquez dedans, puis Références › Mettre à jour la table, dans le groupe Légendes.

Comment changer l'apparence des légendes ?

Modifiez le style « Légende » : toutes les légendes changent ensemble.
