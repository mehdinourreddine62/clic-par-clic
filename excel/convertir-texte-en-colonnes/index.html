Séparer un texte en colonnes

Répartir des données collées dans une seule colonne.

fx

Un fichier importé arrive souvent avec tout dans la même colonne.

Cette leçon vous a aidé ?

Clavier : ← → pour changer d'étape, Espace pour lancer ou mettre en pause.

Syntaxe Données › Convertir
Délimité
Les valeurs sont séparées par un caractère
Séparateur
Point-virgule, virgule, tabulation ou espace
Résumé écrit des étapes
  1. Un fichier importé arrive souvent avec tout dans la même colonne.
  2. Sélectionnez la colonne, puis Données › Convertir.
  3. Indiquez le caractère qui sépare les valeurs : ici, le point-virgule.
  4. Chaque valeur prend sa colonne, et les nombres redeviennent de vrais nombres.

Comment séparer le contenu d'une cellule en plusieurs colonnes dans Excel ?

Quand un fichier importé arrive avec toutes les données dans une seule colonne, séparées par un point-virgule, une virgule ou un espace, Données › Convertir les répartit dans plusieurs colonnes. Les nombres redeviennent de vrais nombres, utilisables dans les calculs.

Exemple

Données › Convertir › Délimité › Point-virgule

« Durand;Lille;120 » devient trois colonnes : Durand, Lille et 120.

Erreurs fréquentes

  • Des données écrasées à droiteLes colonnes voisines doivent être vides : insérez des colonnes avant de convertir.
  • Des codes qui perdent leurs zérosChoisissez le format Texte pour cette colonne à la dernière étape de l'assistant.

Questions fréquentes

Comment séparer un prénom et un nom ?

Choisissez l'espace comme séparateur, ou utilisez le remplissage instantané (Ctrl + E).

Existe-t-il une formule ?

Oui, FRACTIONNER.TEXTE dans Microsoft 365, ou TEXTE.AVANT et TEXTE.APRES.

Comment ouvrir un fichier CSV correctement ?

Données › À partir d'un fichier texte/CSV, puis choisissez le séparateur.
