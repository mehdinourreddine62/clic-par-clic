VPM : calculer une mensualité

Savoir combien on rembourse chaque mois pour un emprunt.

fx

VPM calcule une mensualité : le taux par mois, le nombre de mois, le montant emprunté.

Clavier : ← → pour changer d'étape, Espace pour lancer ou mettre en pause.

Télécharger le fichier d'exerciceExcel · consignes, données de départ et solution
Syntaxe =VPM(taux/12; années*12; -montant)
taux/12
Le taux par mois
années*12
Le nombre de mensualités
-montant
Le capital emprunté, avec un signe moins
Résumé écrit des étapes
  1. VPM calcule une mensualité : le taux par mois, le nombre de mois, le montant emprunté.
  2. Tout doit être dans la même unité : le taux annuel est divisé par 12, la durée multipliée par 12.
  3. Le signe moins devant le montant donne un résultat positif. Sans lui, VPM affiche un nombre négatif.
  4. Mensualité × nombre de mois : le total réellement remboursé.
  5. La différence avec le montant emprunté est le coût du crédit.
