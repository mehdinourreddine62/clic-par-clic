Syntaxe =ARRONDI(nombre; décimales)
nombre
La valeur à arrondir
décimales
2 pour les centimes, 0 pour un entier, -1 pour la dizaine
Résumé écrit des étapes
  1. Le 2 indique le nombre de décimales à garder.
  2. Avec 0, on obtient un entier. À partir de 0,5, Excel arrondit vers le haut.
  3. Un nombre négatif arrondit à la dizaine (-1) ou à la centaine (-2).

Comment arrondir un nombre dans Excel ?

ARRONDI arrondit un nombre au nombre de décimales choisi : 2 pour les centimes, 0 pour un entier, -1 pour la dizaine. À partir de 5, Excel arrondit vers le haut. Contrairement au format de cellule, ARRONDI change vraiment la valeur utilisée dans les calculs.

Exemple

=ARRONDI(B2;2)

7,8865 devient 7,89. Avec 0 décimale : 8. Avec -1 : 10.

Erreurs fréquentes

  • Des totaux qui ne tombent pas justeLe format n'affiche que 2 décimales mais les calculs utilisent toutes les décimales : arrondissez avec ARRONDI.
  • Vouloir toujours arrondir vers le hautARRONDI suit la règle du 5 : utilisez ARRONDI.SUP pour arrondir toujours au-dessus.

Questions fréquentes

Quelle différence avec le bouton « Réduire les décimales » ?

Le bouton change seulement l'affichage ; ARRONDI change la valeur.

Comment arrondir à 0,5 près ?

Utilisez ARRONDI.AU.MULTIPLE : =ARRONDI.AU.MULTIPLE(B2;0,5).

Comment garder la partie entière sans arrondir ?

Utilisez ENT ou TRONQUE.
