Clavier : ← → pour changer d'étape, Espace pour lancer ou mettre en pause.

Résumé écrit des étapes
  1. Le Nord totalise 430.
  2. Corrigez une vente dans les données : le tableau croisé ne bouge pas. Il affiche toujours 430.
  3. Cliquez sur Actualiser : le tableau relit les données et se met à jour.
  4. Prenez le réflexe d'actualiser avant de lire un tableau croisé. Raccourci : Alt + F5.

Pourquoi mon tableau croisé dynamique ne se met-il pas à jour ?

Un tableau croisé dynamique ne se recalcule pas tout seul quand les données changent : il garde une copie en mémoire. Cliquez dans le tableau croisé, puis Analyse du tableau croisé › Actualiser, ou Alt + F5. Pour tous les tableaux croisés du classeur : Actualiser tout, ou Ctrl + Alt + F5.

Analyse du tableau croisé › Actualiser

Le Nord affiche 430. Une vente corrigée dans les données ne change rien ; après Actualiser, le total du Nord est recalculé.

Erreurs fréquentes

  • Les nouvelles lignes ne sont pas prisesLa source est une plage fixe : Modifier la source de données, ou mettez les données sous forme de tableau.
  • La mise en forme disparaîtOptions du tableau croisé › cochez Conserver la mise en forme des cellules lors de la mise à jour.

Questions fréquentes

Peut-on actualiser automatiquement ?

Options du tableau croisé › Données › Actualiser les données lors de l'ouverture du fichier.

Actualiser modifie-t-il les données ?

Non : seul le tableau croisé est relu.

Pourquoi des éléments supprimés restent dans les filtres ?

Options › Données › Nombre d'éléments à retenir par champ : Aucun.
