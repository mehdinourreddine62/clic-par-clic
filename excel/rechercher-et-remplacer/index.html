Résumé écrit des étapes
  1. Ctrl + F recherche un texte dans toute la feuille.
  2. Ctrl + H ouvre Remplacer : indiquez l'ancien texte et le nouveau.
  3. « Remplacer tout » corrige toutes les cellules d'un coup.
  4. Sélectionnez d'abord une colonne pour limiter le remplacement à cette zone.

Comment rechercher et remplacer dans Excel ?

Ctrl + F recherche un texte ou un nombre dans la feuille ; Ctrl + H le remplace par un autre. « Remplacer tout » corrige toutes les cellules d'un coup, par exemple « St- » en « Saint- ». Sélectionnez d'abord une colonne pour limiter le remplacement à cette zone.

Exemple

Ctrl + H › Rechercher : St- › Remplacer par : Saint-

Puis « Remplacer tout » : Excel indique le nombre de remplacements effectués.

Erreurs fréquentes

  • Des remplacements non voulus« Remplacer tout » change aussi les mots qui contiennent le texte : cochez « Totalité du contenu de la cellule » dans Options.
  • Rien n'est trouvéLa recherche est limitée à la sélection, ou l'option « Respecter la casse » est cochée.

Questions fréquentes

Comment chercher dans tout le classeur ?

Options › Dans : Classeur.

Comment annuler un « Remplacer tout » ?

Ctrl + Z juste après.

Peut-on remplacer dans les formules ?

Oui, avec Options › Regarder dans : Formules.
