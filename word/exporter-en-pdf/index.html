Résumé écrit des étapes
  1. Pour envoyer votre rapport, exportez-le en PDF : il s'affichera à l'identique sur tous les ordinateurs.
  2. Fichier › Exporter › Créer un document PDF/XPS, puis donnez au fichier un nom clair.
  3. Dans Options, cochez « Créer des signets à l'aide des titres », puis cliquez sur Publier.
  4. Le PDF s'ouvre : vérifiez le sommaire, les numéros de page et les images avant de l'envoyer.
  5. Autre méthode : Fichier › Enregistrer sous, puis choisissez « PDF » dans la liste des types.

Comment enregistrer un document Word en PDF ?

Un PDF garde exactement la mise en page de votre document : polices, images, numéros de page, quel que soit l'ordinateur qui l'ouvre. C'est le format à privilégier pour envoyer un rapport ou un mémoire. Word le crée directement, sans logiciel supplémentaire.

Le chemin dans Word

Fichier › Exporter › Créer un document PDF/XPS

Ou Fichier › Enregistrer sous, puis le type « PDF ».

Erreurs fréquentes

  • Des marques de révision dans le PDFAcceptez toutes les modifications et supprimez les commentaires avant d'exporter.
  • Un sommaire avec de faux numérosMettez la table des matières à jour juste avant d'exporter.

Questions fréquentes

Le PDF peut-il être modifié ensuite ?

Pas facilement : gardez toujours votre fichier Word pour les corrections.

Comment exporter seulement quelques pages ?

Dans la fenêtre de publication, cliquez sur Options et choisissez les pages.

Comment rendre le PDF plus léger ?

Choisissez « Taille minimale (publication en ligne) » dans « Optimiser pour ».
