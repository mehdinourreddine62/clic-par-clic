FILTRE

Extraire les lignes d'un tableau qui respectent une condition.

fx

Une seule formule en E3 : le résultat se propage dans les cellules voisines.

Cette leçon vous a aidé ?

Clavier : ← → pour changer d'étape, Espace pour lancer ou mettre en pause.

Syntaxe =FILTRE(tableau; condition; [si_vide])
tableau
Les lignes à filtrer
condition
Le test appliqué à chaque ligne
si_vide
Le texte affiché si aucune ligne ne correspond
Version
Excel 2021 et Microsoft 365
Résumé écrit des étapes
  1. Une seule formule en E3 : le résultat se propage dans les cellules voisines.
  2. Changez le critère : la liste se met à jour.
  3. Pour combiner deux conditions, multipliez-les, chacune entre parenthèses.

Comment utiliser la fonction FILTRE dans Excel ?

FILTRE extrait automatiquement les lignes d'un tableau qui respectent une condition : les employés d'un service, les ventes d'un mois. Une seule formule suffit, le résultat se propage dans les cellules voisines et se met à jour dès que les données ou le critère changent.

Exemple

=FILTRE(A2:C20;B2:B20="Ventes";"Aucun")

Renvoie toutes les lignes du service Ventes, ou « Aucun » s'il n'y en a pas.

Erreurs fréquentes

  • #PROPAGATION!Des cellules sous la formule ne sont pas vides : libérez la place.
  • #CALC!Aucune ligne ne correspond : ajoutez le troisième argument, par exemple "Aucun".

Questions fréquentes

Comment combiner deux conditions ?

Multipliez-les pour ET : (B2:B20="Ventes")*(C2:C20>3000) ; additionnez-les pour OU.

Comment trier le résultat ?

Entourez avec TRIER : =TRIER(FILTRE(…)).

Dans quelle version d'Excel ?

Microsoft 365 et Excel 2021 ou plus récent.
